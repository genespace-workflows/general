# Общий сценарий контроля качества
Анализ многих геномных данных начинается с общих процедур, включая контроль качества входных данных.

Для этого на языке Nextflow написан специальный сценарий. 
Входными данными для этого сценария являются FASTQ-файлы, полученные в ходе секвенирования.

Сценарий состоит из 3 шагов:
* программа FastQC - контроль качества прочтений;
* программа MultiQC - сводный отчет по качеству всех прочтений в проекте;
* вызов биоинформатической платформы для разбора и загрузки результатов отчета, сгенерированного программой MultiQC в базу данных проекта.

Данный сценарий показывает пример бесшовной интеграции между сценариями и биоинформатической платформой:
* при нажатии кнопки "Контроль качества" биоинформатическая платформа запускает преднастроенный сценарий для контроля качества данных. 
* в ходе выполнения сценария, платформа Nextflow:
  * выкладывает полученный отчет по контролю данных в заданную биоинформатической платформой директорию на сервере, 
    чтобы пользователь мог просмотреть этот отчет через веб-интерфейс платформы;
  * через специальный вызов к контроллеру биоинформатической платформы, который передается как параметр в скрипт Nextflow, 
    платформа Nextflow обращается к биоинформатической платформе для для разбора и загрузки результатов отчета, сгенерированного программой MultiQC в базу данных проекта.

Такой подход позволяет:
* скрыть от пользователя (врач, лаборант и т.п.) сложность работы со сценариями, пользователь работает через простой веб-интерфейс;
* обеспечить гибкую настройку биоинформатической платформы.
